GitHub電腦同步

想要利用 GitHub 在不同電腦之間同步 Sublime Text 的設定與外掛（Package Control），最常見且有效的方式是使用專門的套件 Sync Settings（結合 GitHub Gist）。
這個套件能將你的個人設定檔、快速鍵以及已安裝的外掛清單自動上傳與下載。以下是完整的設定步驟：
第一步：
建立 GitHub Personal Access Token因為需要透過程式將資料同步到你的 GitHub 帳號，所以必須先申請一組權限憑證：登入你的 GitHub 帳號，點擊右上角頭像進入 Settings（設定）。
滑到最下方，點擊 Developer settings。
選擇 Personal access tokens -> Tokens (classic)。
點擊 Generate new token (classic)。
在 Note 欄位輸入名稱（例如：Sublime Sync Settings）。
在 Scopes 權限區塊中，勾選 gist（授權存取 Gist 的權限）。
滑到最下方點擊 Generate token。
請務必把產生的一長串 Token 複製並妥善保存（離開這個頁面後它就不會完整顯示了）。
第二步：
在電腦 A 安裝並設定 Sync Settings開啟 Sublime Text，按下快捷鍵叫出指令區： Windows / Linux: Ctrl + Shift + P Mac: Cmd + Shift + P 輸入 Install Package 並按下 Enter，等待套件清單載入。
搜尋 Sync Settings 並按下 Enter 進行安裝。安裝完成後，前往選單路經：Preferences -> Package Settings -> Sync Settings -> Settings – User（或透過 Command Palette 輸入 Sync Settings: Open Settings）。
在開啟的 JSON 檔案中，填入你的 GitHub Token：JSON{ "access_token": "你的_GitHub_Token_貼在這裡" } 儲存檔案。
第三步：
上傳設定至 GitHub (Gist)在電腦 A 上的 Sublime Text 按下 Ctrl + Shift + P（Mac 則是 Cmd + Shift + P）。
輸入並執行指令：Sync Settings: Backup（或選擇 Create and Upload）。
執行後，它會自動把你的設定打包並上傳到你的 GitHub Gist。
重要步驟：上傳成功後，Sublime Text 的視窗下方訊息欄（或設定檔內）會回傳一個 gist_id。
請把這個 ID 複製起來（它是一串很長的英數字串）。
再次打開你的 Settings – User，把 gist_id 補上去並儲存：
JSON{ "access_token": "你的_GitHub_Token", "gist_id": "剛剛產生的_Gist_ID" }
第四步：
在電腦 B（或其他新電腦）同步設定當你在另一台電腦想要套用相同的 Sublime Text 環境時：在新電腦安裝好 Sublime Text。
同樣透過 Package Control 安裝 Sync Settings 套件。打開 Settings – User，填入相同的 access_token 以及剛剛取得的 gist_id：
JSON{ "access_token": "你的_GitHub_Token", "gist_id": "你的_Gist_ID" }
按下 Ctrl + Shift + P（Mac 用 Cmd + Shift + P），輸入並執行：Sync Settings: Restore（或選擇 Download）。
稍等片刻，它就會自動從 GitHub 下載你的個人設定、佈景主題與外掛清單，並自動透過 Package Control 安裝對應的外掛。
重啟 Sublime Text 即可完成同步！

另一台電腦設定

當你在另一台新電腦（或另一台需要同步的電腦）想要把設定拉過來時，只需要簡單的幾個步驟就能搞定：
第一步：安裝 Sublime Text 與基本套件
在新電腦上下載並安裝 Sublime Text。
確保安裝好 Package Control（如果還沒裝，透過指令區輸入 Install Package Control 即可快速安裝）。
第二步：安裝 Sync Settings 套件
按下快捷鍵 Ctrl + Shift + P（Mac 是 Cmd + Shift + P）叫出指令區。
輸入 Install Package 並按下 Enter。
搜尋並安裝 Sync Settings。
第三步：填入你的 Token 與 Gist ID
安裝完成後，同樣按下 Ctrl + Shift + P，輸入 sync。
點擊 Sync Settings: Edit User Settings 打開設定檔。
把你之前備妥的 JSON 內容（包含你的 access_token 以及你的 gist_id）完整貼進去：
JSON { "access_token": "ghp_sRl4jG3rMVIPL0rHeleyW4ruvnLRX2jhQTN", "gist_id": "你的_Gist_ID" } 按下 Ctrl + S 存檔。
第四步：下載並套用設定（Restore）
再次按下 Ctrl + Shift + P（Mac 是 Cmd + Shift + P）。
輸入並執行：Sync Settings: Download（有些版本也叫 Sync Settings: Restore）。
稍等幾秒鐘，右下角會顯示下載與安裝外掛的進度。
完成！ 等它跑完後，重新啟動 Sublime Text，你原本的主題、快速鍵和所有外掛就會全部同步過來了！
